# Manual de Usuario: AI Assistant & Agent (v4.0)

NanoEditor integra una IA avanzada con capacidades agénticas que puede razonar y actuar sobre tu código.

## 🚀 Funcionalidades Implementadas
- [x] **AI Chat Contextual:** Chat con historial persistente que entiende el archivo abierto.
- [x] **Streaming de Respuestas:** Visualización de la respuesta en tiempo real para una mejor UX.
- [x] **Selección de Modelos:** Soporte para 13+ modelos mediante Gemini y LiteLLM (OpenAI, Anthropic, etc.).
- [x] **Modo Agente:** La IA puede ejecutar comandos, leer/escribir archivos y realizar tareas complejas de forma autónoma.
- [x] **Contexto Global:** Conocimiento automático de la estructura del proyecto y archivos clave.
- [x] **Limpieza Automática:** El código generado se limpia de etiquetas Markdown para inserción directa.
- [x] **Optimización de Código:** Comando dedicado para mejorar el fragmento seleccionado.

## 🛠️ Próximos Pasos (Pendiente)
- [ ] **AI Code Completion:** Sugerencias de código en línea tipo "Ghost Text" mientras escribes.
- [ ] **Auto-Bug Detection:** Escaneo en segundo plano para detectar errores potenciales con IA.
- [ ] **Explicación de Errores Dinámica:** La IA explica los errores de la terminal automáticamente.

## 📖 Instrucciones de Uso
1. Abre el panel de **AI Chat** (ícono de mensaje/cerebro).
2. Escribe tu pregunta o petición (ej: "Refactoriza esta función para que sea asíncrona").
3. Usa `/agente` (si el comando está configurado) para activar tareas autónomas.
4. Selecciona el modelo deseado en el desplegable superior.
5. Copia o inserta el código generado directamente en tu editor.
