# Manual de Usuario: Terminal Interactivo (v4.0)

Una terminal integrada potente que soporta ejecución de scripts y herramientas de línea de comandos.

## 🚀 Funcionalidades Implementadas
- [x] **Soporte `input()`:** Puedes interactuar con programas Python que requieran entrada del usuario.
- [x] **Colores ANSI:** Soporte completo para colores y estilos en la terminal.
- [x] **Backend Independiente:** La terminal corre en un proceso separado para no bloquear el editor.
- [x] **Auto-scroll:** La terminal se desplaza automáticamente a la última salida generada.
- [x] **Historial de Comandos:** Navega por comandos anteriores con las flechas.

## 🛠️ Próximos Pasos (Pendiente)
- [ ] **Múltiples Terminales:** Pestañas para tener varias sesiones abiertas simultáneamente.
- [ ] **Temas de Color:** Personalización de los colores de la terminal.
- [ ] **Persistencia de Sesión:** Mantener la sesión abierta al cerrar el panel.

## 📖 Instrucciones de Uso
1. Abre el panel de la **Terminal** (parte inferior o atajo configurado).
2. Escribe cualquier comando (ej: `ls`, `python main.py`, `pip install`).
3. Si el programa pide datos, escríbelos directamente y presiona `Enter`.
4. Botón **Clear** para limpiar la pantalla.
